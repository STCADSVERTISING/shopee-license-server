# 📡 ShopFlow Online License Server (เซิร์ฟเวอร์เช็คสิทธิ์คีย์ออนไลน์)

โฟลเดอร์นี้บรรจุซอร์สโค้ดระบบหลังบ้านของ **Online License Server** สำหรับผู้พัฒนา (คุณ SITTH) เพื่อเปลี่ยนโมเดลธุรกิจของบอท **ShopFlow Automate Pro** ให้กลายเป็น **"ระบบคีย์ออนไลน์" (1 คีย์ล็อกใช้งานได้ 1 เครื่องพร้อมกัน แต่ย้ายเครื่องได้เองเมื่อล็อกเอาท์)**

---

## 🛠️ โครงสร้างไฟล์และสถาปัตยกรรมระบบคีย์

1.  **`index.js`**: ไฟล์ระบบหลักเขียนด้วย Node.js + Express
    *   มี API เช็คสิทธิ์และลงทะเบียนล็อกเครื่อง: `/validate`
    *   มี API ปลดการล็อกเครื่องเพื่อย้ายสิทธิ์ (Logout Key): `/deactivate`
    *   มี API สำหรับแอดมินในการ เจนคีย์, รีเซ็ตรหัสเครื่องแมนนวล และสั่งแบนคีย์
2.  **`admin-panel.html`**: หน้าแดชบอร์ดจัดการภาพผู้พัฒนาแบบส่วนตัว (Admin Key Manager)
    *   คุณ SITTH สามารถดับเบิลคลิกเปิดหน้าต่างนี้ขึ้นมาบนหน้าจอคอมพิวเตอร์ของคุณเองจากที่ไหนก็ได้
    *   ป้อนลิงก์เซิร์ฟเวอร์ และรหัสผ่านความปลอดภัย (Admin API Key) เพื่อกดยิงเชื่อมต่อ
    *   **กดสร้างคีย์บอทใหม่** (มีประเภททดลอง 7 วัน, รายเดือน 30 วัน, และตลอดชีพถาวร) ตัวระบบจะดึงรหัสลงดิสก์และ **คัดลอกรหัสคีย์สั้น เช่น `SF-ABCD-EFGH` ลงคลิปบอร์ดให้ทันที** ส่งมอบให้ลูกค้าได้รวดเร็วที่สุด!
    *   **ดูประวัติลูกค้า:** ตารางจะดึงข้อมูลทันทีว่าคีย์ใบไหนเปิดใช้งานแล้ว เครื่อง HWID รหัสอะไร หรือคีย์ไหนยังไม่ถูกเปิดใช้งาน
    *   **ปลดล็อกลูกค้าแมนนวล:** มีปุ่ม `🔓 ปลดล็อคเครื่อง` ในกรณีที่ลูกค้าลบโปรแกรมทิ้งไปโดยไม่ได้กด Logout ช่วยให้ลูกค้าเอาคีย์ไปกรอกเครื่องใหม่ได้ทันที
    *   **สั่งแบนคีย์:** มีปุ่ม `🗑️ ระงับ` เพื่อสั่งลบคีย์ออกจากระบบออนไลน์ บล็อกการทำงานของบอทเครื่องนั้นในทันที

## 📦 1. วิธีทดสอบการทำงานออนไลน์แบบออฟไลน์ (Local Simulation) — *มีพร้อมทดสอบทันที!*

เพื่อไม่ให้คุณ SITTH ต้องเสียเวลาติดตั้งเซิร์ฟเวอร์ตั้งแต่ก้าวแรก ผมได้สร้าง **"ระบบจำลองเซิร์ฟเวอร์ออนไลน์" (Local Simulation Database)** ไว้ในตัวโปรแกรมบอทหลักโดยอัตโนมัติแล้วครับ!

*   ที่ตัวโปรแกรมบอทหลัก ค่าเริ่มต้นของเซิร์ฟเวอร์เช็คสิทธิ์คีย์จะถูกตั้งค่าเป็น: **`local-simulation`**
*   บอทจะไปสแกนหาไฟล์จำลองที่ถูกสร้างขึ้นในโฟลเดอร์โครงการชื่อ: **`online_keys_simulation.json`**
*   คุณ SITTH สามารถทดลองนำคีย์จำลองด้านล่างนี้ไปกรอกทดสอบการทำงานของบอทได้ทันทีครับ:
    *   🔑 **`SF-TRIAL-7777`** (คีย์ทดลองใช้ฟรี 7 วัน) — *ยังว่าง นำไปเปิดใช้งานได้*
    *   🔑 **`SF-MONTHLY-3030`** (คีย์รายเดือน 30 วัน) — *ยังว่าง นำไปเปิดใช้งานได้*
    *   🔑 **`SF-LIFETIME-9999`** (คีย์ตลอดชีพ Pro ถาวร) — *ยังว่าง นำไปเปิดใช้งานได้*
    *   🔑 **`SF-LOCKED-8888`** (คีย์ติดล็อก) — *มีรหัสเครื่องอื่นใช้งานอยู่แล้ว หากลูกค้ากรอก จะเด้งข้อความสีแดงเตือนให้ถอนสิทธิ์เครื่องเก่าก่อน*

## 🚀 2. วิธีนำระบบเซิร์ฟเวอร์เช็คสิทธิ์ขึ้นระบบออนไลน์จริงแบบฟรี 100% (Render.com Deployment)

เมื่อพร้อมปล่อยขายให้ลูกค้าใช้งานจริง แนะนำให้นำซอร์สโค้ดในโฟลเดอร์ `online-license-server/` นี้ขึ้นคลาวด์ **Render.com** (เป็นระบบบริการคลาวด์ยอดนิยมสำหรับนักพัฒนา ที่เปิดให้รัน Node.js API และบันทึกไฟล์ได้ฟรี ไม่มีค่าบริการรายเดือนใดๆ ทั้งสิ้น)

### 📌 ขั้นตอนการติดตั้งออนไลน์:
1.  สมัครสมาชิกที่เว็บ [https://render.com/](https://render.com/) (เชื่อมต่อด้วยบัญชี GitHub หรือ Google ได้เลย)
2.  กดปุ่ม **`New +`** สีน้ำเงินขวาบน เลือก **`Web Service`**
3.  เลือกประเภทเชื่อมโยงกับ GitHub Repository ของคุณ หรือถ้าอัปโหลดโฟลเดอร์ขึ้น GitHub แล้วให้เลือก Repo นั้นมาติดตั้งได้เลย
4.  กรอกค่ารายละเอียดบิวด์ของ Render:
    *   **Name:** `shopee-license-server` (หรือชื่อบอทของคุณ)
    *   **Runtime:** `Node`
    *   **Build Command:** `npm install`
    *   **Start Command:** `npm start`
    *   **Plan:** เลือก **`Free`** ($0 / month)
5.  *(สำคัญที่สุด)* เลื่อนลงมาที่หัวข้อ **`Advanced`** -> กดปุ่ม **`Add Environment Variable`** เพื่อกำหนดรหัสผ่านแอดมินและการซิงค์คลาวด์คีย์ไม่ให้สูญหาย:
    *   **Key:** `ADMIN_API_KEY`
    *   **Value:** `ตั้งค่ารหัสลับแอดมินของคุณเอง` (เช่น `SITTH_PRO_SECRET_999`) *รหัสนี้จะนำไปป้อนในแดชบอร์ด admin-panel.html*
    *   *(แนะนำเพิ่มเติมเพื่อเซฟข้อมูลคีย์ให้ถาวรฟรี 100%)* ใส่ตัวแปรเพิ่มเติมเหล่านี้:
        *   **Key:** `GITHUB_GIST_ID`
        *   **Value:** `รหัส Gist ID ส่วนตัวของคุณ` (ดูขั้นตอนสร้างด้านล่าง)
        *   **Key:** `GITHUB_TOKEN`
        *   **Value:** `GitHub Personal Access Token ของคุณ` (ขึ้นต้นด้วย ghp_...)
6.  กดปุ่ม **`Create Web Service`** ด้านล่างสุด คอยประมาณ 2-3 นาที ระบบจะคอมไพล์เสร็จสิ้นและแสดงลิงก์ออนไลน์สีเขียวมาให้ เช่น:
    *   👉 **`https://shopee-license-server.onrender.com`**
7.  ทดลองเปิดหน้านั้นบนเบราว์เซอร์ ถ้าขึ้นคำว่า `📡 ShopFlow License Server Online` แสดงว่าระบบออนไลน์จริงพร้อมเชื่อมต่อกับลูกค้าแล้วครับ!

### 📡 วิธีสร้าง GitHub Gist เป็นฐานข้อมูลคลาวด์ถาวรฟรี 100% (คุ้มค่ามาก!)
เนื่องจากเซิร์ฟเวอร์ Render ฟรีจะไม่มีฮาร์ดดิสก์แบบถาวร (ไฟล์ `database.json` อาจถูกรีเซ็ตค่าเริ่มต้นเมื่อบริการรีบูตตัวเอง) เราจึงแนะนำให้เชื่อมระบบเข้ากับ **GitHub Gist** ซึ่งเก็บข้อมูลถาวรฟรี 100% และมีความมั่นคงสูงมาก:

1. ล็อกอินเข้าใช้งานบัญชี [GitHub.com](https://github.com/) (หากไม่มีให้สมัครใหม่ได้ฟรี)
2. เปิดเบราว์เซอร์ไปที่ [https://gist.github.com/](https://gist.github.com/)
3. ทำการกรอกสร้างไฟล์จำลองดังนี้:
   *   **Gist description...**: กรอกคำอธิบาย เช่น `ShopFlow License Database`
   *   **Filename including extension...**: กรอกชื่อไฟล์ให้เป็น `database.json`
   *   **เนื้อหาด้านในไฟล์**: กรอกโค้ดสัญญาสั้นๆ เริ่มต้นเป็น `{"keys": []}`
   *   กดปุ่ม **`Create secret Gist`** (สร้างจิสต์ลับที่จะเห็นได้ผ่านการสิทธิ์เชื่อมด้วยคีย์ส่วนตัวเท่านั้น)
4. เมื่อสร้างเสร็จแล้ว ให้คัดลอก **รหัสจิสต์ (GIST_ID)** จากบน Address Bar ของบราวเซอร์:
   *   ตัวอย่าง URL: `https://gist.github.com/username/c7b2c0182b8a36d9ac3f4b4f57a9f99f`
   *   รหัสอักษรผสมตัวเลขต่อจากชื่อยูสเซอร์เนมด้านท้ายสุดนั่นคือ: **`c7b2c0182b8a36d9ac3f4b4f57a9f99f`** (ก๊อปปี้รหัสของท่านเองไว้)
5. สร้างรหัสสิทธิ์ล็อกอินเข้าถึง Gist:
   *   เปิดลิงก์ [https://github.com/settings/tokens](https://github.com/settings/tokens)
   *   กดปุ่ม **`Generate new token`** -> เลือก **`Generate new token (classic)`**
   *   ช่อง **Note**: กรอก `ShopFlow-API-Token`
   *   ติ๊กถูกที่ช่องสิทธิ์ **`[x] gist`** (สิทธิ์ควบคุม Gist) เท่านั้นเพื่อความปลอดภัย
   *   เลื่อนลงด้านล่างสุดกด **`Generate token`**
   *   ทำการคัดลอครหัส Token ยาวๆ ที่ขึ้นต้นด้วย **`ghp_...`** เก็บไว้ทันที (ระบบจะโชว์ให้เห็นเฉพาะในหน้านี้เท่านั้น)
6. นำค่า **GIST_ID** และ **ghp_...** ไปกรอกในช่อง Environment Variables บนระบบ Render ตามที่ระบุไว้ในขั้นตอนที่ 5 ด้านบน
7. **เรียบร้อย!** ข้อมูลคีย์ออนไลน์ทั้งหมดของคุณ SITTH จะวิ่งเข้าไปจัดเก็บ ซิงค์อัปเกรดใน GitHub Gist ส่วนตัวอย่างถาวร ข้อมูลปลอดภัย 100% ไม่สูญหายอีกตลอดไป! และคุณยังสามารถกดเข้ามาแก้ไข เพิ่ม หรือลดรายชื่อคีย์ได้โดยตรงจากเบราว์เซอร์ของคุณเองด้วยครับ!
